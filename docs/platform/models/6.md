# Phase 6 — Course Management Service

This is the **heart of your platform**.

Everything learners purchase, enroll in, or study is a **Course**.

A course belongs to **one Institution**.

A course contains:

* Modules
* Lessons
* Quizzes
* Assignments
* Certificates
* Pricing
* Membership Rules

Think of it as:

> **Udemy Course + YouTube Playlist + Graphy Batch**

---

# Goal

Allow institutions to create, manage, publish, archive, duplicate, and organize courses.

# Business Rules

* Every course belongs to exactly one institution.
* Only users with `course.create` permission can create courses.
* New courses always start as **DRAFT**.
* A course cannot be published until it has at least one module and one lesson.
* Slugs are automatically generated and remain unique.
* Thumbnail and intro video reference uploaded files from the Storage Service.
* Deleting a course performs a soft delete.
* Duplicated courses copy metadata but start as **DRAFT** without enrollments or analytics.
* Public APIs return only `PUBLISHED` courses with `PUBLIC` visibility.
