# Phase 8 — Student Enrollment & Learning Management

This phase creates the connection between **Learners** and **Courses**.

Until now, you've built the creator side. This phase begins the learner journey.

```text
User
    ↓
Enroll
    ↓
Course
    ↓
Learning Progress
    ↓
Continue Learning
```

This phase **does not** include quizzes or certificates. Those come later.

---

# Goal

Allow learners to:

* Enroll in courses
* Leave courses
* Continue learning
* Track progress
* Bookmark lessons
* View enrolled courses
* Track learning history

# Validation Rules

### Enrollment

* User must be authenticated.
* User cannot enroll twice in the same active course.
* Course must be published.
* User must satisfy the course access rule.
* Enrollment creates an initial course progress record.

### Lesson Progress

* Progress can only increase (unless manually reset).
* Progress percentage: 0–100.
* Completing a lesson automatically updates course progress.
* Progress updates require an active enrollment.

### Bookmarks

* Timestamp must be within the lesson duration.
* Each bookmark belongs to one learner and one lesson.

# Business Rules

* A learner may have only one active enrollment per course.
* Enrollment is the prerequisite for accessing protected lessons.
* Lesson progress is saved automatically during learning.
* Completing a lesson recalculates overall course progress.
* "Continue Learning" always returns the learner's last unfinished lesson.
* Bookmarks are personal and are not visible to instructors.
* Course completion is achieved when all required lessons are completed.
* Progress records are never deleted; they remain for analytics and certificates.
* If enrollment expires, lesson access is revoked but progress is retained.
