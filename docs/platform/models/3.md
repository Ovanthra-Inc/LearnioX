# Phase 3 — Institution Service (Academy Management)

This is the **core domain** of your entire platform.

Everything revolves around an **Institution (Academy)**.

A Course belongs to an Institution.

A Teacher belongs to an Institution.

Students enroll into Institution Courses.

Payments belong to Institution.

Analytics belong to Institution.

Think of Institution as **YouTube Channel + Organization + Company + LMS Workspace**.

---

# Goal

Allow a user to create and manage an institution.

Initially:

* One Owner
* Public Institution Page
* Basic Settings

Later phases will add

* Team Members
* Roles
* Payments
* Analytics
* AI
* Marketing

# Business Rules

* Every authenticated user can create an institution (subject to future plan limits).
* One user can own multiple institutions.
* Each institution has exactly one owner in this phase.
* Institution branding (logo, banner, favicon) references files uploaded through the Storage Service using `file_id`; binary files are never stored in the institution table.
* Slugs are globally unique and are used for public URLs.
* New institutions start in **DRAFT** status and become publicly visible only after being published.
* Public endpoints only return institutions with `ACTIVE` status and `PUBLIC` visibility.
* Deleting an institution performs a soft delete so it can be restored later.
