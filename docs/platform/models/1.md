# Phase 1 — Authentication Service

## Goal

Authenticate users using **Google OAuth only**.

No username/password.

Every authenticated user is a **User**.

Later this same user can become:

* Learner
* Institution Owner
* Instructor
* Team Member
* Admin

# Security Rules

* OAuth provider: Google only.
* Access tokens expire in **15–30 minutes**.
* Refresh tokens expire in **30 days**.
* Store only **hashed refresh tokens**.
* Rotate refresh tokens on every refresh request.
* Mark revoked tokens instead of deleting them immediately.
* Use HTTPS in production.
* Validate Google ID tokens before trusting user data.
* Use UUIDs for all primary keys.
* Return a consistent error format for all authentication failures.

This Phase 1 gives you a solid authentication foundation that will support every later module (institutions, courses, enrollments, roles, analytics, and AI) without requiring redesign.
